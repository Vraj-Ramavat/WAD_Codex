The ORIGINAL WAD_review backend is restored without alteration by running `npm run setup`
from the project root. This folder is intentionally not replaced by newly-written backend
logic. The setup script pins the upstream source to commit
6c48d2660dce5646578b4b3ea04eae142ed9614a and copies the original `backend/` directory.
Internet access and Git are required for this one-time setup.
